# 🏸 Pacita Sports Reservation System

The Pacita Sports Reservation System is a web-based application designed to simplify the process of reserving sports facilities such as basketball, badminton, tennis, and volleyball courts. It provides an organized and user-friendly platform for both administrators and users.

## 🔧 Features

### 👨‍💼 Admin Features
- Manage courts (add, edit, delete)
- Set court availability and maintenance schedules
- View and manage all bookings
- Approve, cancel, or delete reservations
- Create and manage events or tournaments
- Manage user accounts
- Post announcements

### 👤 User Features
- Register and log in to the system
- View court availability in real-time
- Reserve courts with time slots
- View and manage personal bookings
- Join events or tournaments
- View announcements and updates

## 🛠️ Technologies Used
- PHP (Backend)
- MySQL (Database)
- HTML, CSS (Frontend)
- XAMPP / 000webhost (Deployment)

## 🎯 Purpose
This system was developed to improve the efficiency of managing sports facility reservations while ensuring fairness, accessibility, and ease of use for both administrators and users.
